# ADR 0010: Planned AWS architecture

Implemented as a statically validated Terraform stack, not deployed. ECS/Fargate runs the API, worker, UI, and demo services; ECR holds images; private RDS and ElastiCache hold state/cache; ALB terminates HTTPS; Secrets Manager provides credentials; CloudWatch collects logs. ALB access is restricted to operator-supplied CIDRs. Broad exposure is deferred until API authentication and atomic concurrency control are complete.
